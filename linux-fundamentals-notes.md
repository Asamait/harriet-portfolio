## Introduction to Linux

Linux is an open-source operating system widely used in servers, cybersecurity, cloud computing, and networking environments.

Key advantages:
- Open source
- Secure and stable
- Highly customizable
- Powerful command-line tools

---
Major Linux distributions include:

- Ubuntu
- Debian
- Fedora
- Kali Linux
- Red Hat Enterprise Linux

Linux is popular because it is **secure, stable, and customizable**.


## Basic Linux Commands

### 1. Checking Current Directory

pwd

Displays the current working directory.

---

### 2. Listing Files

ls
ls -l
ls -a

Shows files and directories.

---

### 3. Changing Directory

cd foldername

Moves to another directory.

Example:

cd Documents

---

### 4. Creating Directories

mkdir projects

Creates a new directory.

---

### 5. Creating Files

touch file.txt

Creates an empty file.

---

### 6. Removing Files

rm file.txt

Deletes a file.

---

## File Permissions

Linux uses permissions to control access.

Example command:

chmod 755 script.sh

Permission meaning:

Owner | Group | Others

---

## Checking System Information

uname -a

Displays Linux system information.

---

## Package Management

For Ubuntu / Debian systems:

sudo apt update
sudo apt upgrade
sudo apt install package-name

Example:

sudo apt install git

---

## Networking Commands in Linux

Checking IP address:

ip a

Testing connectivity:

ping google.com

Checking network routes:

traceroute google.com

---

## Best Practices

- Use strong passwords
- Keep the system updated
