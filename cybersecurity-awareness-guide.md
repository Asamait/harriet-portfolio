# 1. Introduction to Cybersecurity

Cybersecurity is the practice of protecting computer systems, networks, and data from digital attacks.

Cyberattacks usually aim to:

- Steal sensitive information
- Disrupt systems
- Gain unauthorized access
- Destroy or manipulate data

Cybersecurity is essential for individuals, businesses, and governments.

---

# 2. Types of Cyber Threats

## Malware

Malware means **malicious software** designed to harm or exploit systems.

Examples include:

- Viruses
- Worms
- Trojans
- Spyware
- Ransomware

---

## Phishing

Phishing is a cyberattack where attackers trick users into revealing sensitive information.

Example:

A fake email pretending to be from a bank asking for login credentials.

---

## Ransomware

Ransomware locks or encrypts files and demands payment to restore access.

Organizations and hospitals are common targets.

---

## Social Engineering

Social engineering attacks manipulate people into revealing confidential information.

Example:

Someone pretending to be IT support asking for passwords.

---

# 3. Common Cybersecurity Attacks

### Password Attacks

Attackers try to guess or steal passwords using methods like:

- Brute force attacks
- Dictionary attacks
- Credential stuffing

---

### Man-in-the-Middle Attack

Attackers intercept communication between two systems.

Example:

Intercepting data on an unsecured Wi-Fi network.

---

### Denial-of-Service (DoS)

A DoS attack overwhelms a system or website with traffic so that legitimate users cannot access it.

---

# 5. Multi-Factor Authentication (MFA)

Multi-factor authentication adds an extra layer of security.

Examples include:

- Password + SMS code
- Password + authentication app
- Password + fingerprint

This makes it much harder for attackers to gain access.

- Use secure HTTPS websites
- Keep software updated
