# 1. Introduction to Computer Networking

Computer networking is the process of connecting computers and devices so they can communicate and share resources such as:

- Files
- Internet connection
- Printers
- Applications

Networking is essential in modern IT environments including:

- Businesses
- Universities
- Data centers
- Cloud infrastructure

---

# 2. Types of Networks

### LAN (Local Area Network)

A LAN connects computers within a small geographic area.

Examples:
- School computer labs
- Office networks
- Home Wi-Fi networks

---

### WAN (Wide Area Network)

A WAN connects networks over large distances.

Example:
The **Internet** is the largest WAN in the world.

---

### MAN (Metropolitan Area Network)

A MAN covers a city or large campus.

Example:
University network infrastructure.

---

# 3. Network Devices

### Router

A router connects multiple networks and directs traffic between them.

Example:
Home internet routers.

---

### Switch

A switch connects devices within the same local network.

Used in:
- Offices
- Schools
- Server rooms

---

### Modem

A modem connects a local network to the internet service provider (ISP).

---

### Access Point

An access point provides wireless connectivity to devices such as:

- Phones
- Laptops
- Tablets

---

# 5. TCP vs UDP

### TCP (Transmission Control Protocol)

Features:

- Reliable communication
- Error checking
- Used in web browsing and email

Example:

HTTP  
HTTPS  
FTP

---

### UDP (User Datagram Protocol)

Features:

- Faster but less reliable
- Used in real-time communication

Example:

Streaming  
Online gaming  
VoIP calls
